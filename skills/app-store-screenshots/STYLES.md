# App Store screenshot styles

Each style is a design system (DNA): palette logic, type pairing, panel treatment, decoration and device treatment. Use it as a guide, never as a template.

| # | Style | Look |
|---|---|---|
| 01 | [Scrapbook Collage Panorama](styles/01-scrapbook-collage-panorama/design.md) | Off-white "paper" panels and sky-photo panels alternate. |
| 02 | [Sky Collage Panorama](styles/02-sky-collage-panorama/design.md) | A continuous blue sky with clouds runs behind every panel. |
| 03 | [Mascot Pop](styles/03-mascot-pop/design.md) | Warm orange gradient panels starring a cute 3D blob mascot that wears props (crown, chef hat) and peeks over phones. |
| 04 | [Brand Blocks](styles/04-brand-blocks/design.md) | Solid brand-colour panels (blue, white, orange, white) with a flat vector mascot bird, big round flag discs, a comparison card and a real-person video on the phone. |
| 05 | [Floating UI](styles/05-floating-ui/design.md) | White panels on a coral background. |
| 06 | [Mascot Hype](styles/06-mascot-hype/design.md) | Electric purple panels with huge italic condensed hype headlines, a furry 3D gorilla mascot, coral pill tags and before/after photo cards. |
| 07 | [Sticker Headline](styles/07-sticker-headline/design.md) | Soft grey-white panels where one word in each headline is replaced by a white sticker containing an icon and a word, with the line partly greyed. |
